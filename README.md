# Трекер полезных привычек

Бэкенд SPA веб-приложения для трекера полезных привычек по методике Джеймса Клира «Атомные привычки».

## Описание проекта

Трекер полезных привычек — это веб-приложение, которое помогает пользователям формировать и поддерживать полезные привычки.

Приложение позволяет:
- Создавать и отслеживать полезные привычки
- Награждать себя за выполнение привычек (вознаграждение или приятная привычка)
- Устанавливать периодичность выполнения (от 1 до 7 дней)
- Контролировать время выполнения (не более 2 минут)
- Просматривать публичные привычки других пользователей
- Получать напоминания через Telegram бота

## Бизнес-правила валидации

1. Исключено одновременное указание вознаграждения и связанной привычки
2. Время выполнения не должно превышать 120 секунд
3. Связанная привычка должна быть приятной
4. У приятной привычки нет вознаграждения и связанной привычки
5. Периодичность не должна превышать 7 дней (нельзя реже раза в неделю)

## Быстрый старт

### Предварительные требования

- Python 3.10 или новее
- Poetry (менеджер зависимостей)
- Redis (для работы Celery)
- SQLite (используется по умолчанию) или PostgreSQL

### Установка и настройка

1. Клонируйте репозиторий:
   git clone https://github.com/ваш-логин/habits-tracker.git
   cd habits-tracker

2. Установите зависимости:
   poetry install

3. Создайте файл .env:
   cp .env.example .env

   Откройте файл .env и заполните значения:
   SECRET_KEY=your-secret-key-here
   DEBUG=True
   ALLOWED_HOSTS=localhost,127.0.0.1
   DB_ENGINE=django.db.backends.sqlite3
   DB_NAME=db.sqlite3
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   TELEGRAM_BOT_NAME=your_bot_username_bot
   CELERY_BROKER_URL=redis://localhost:6379/0
   CELERY_RESULT_BACKEND=redis://localhost:6379/0
   CORS_ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000
   TIME_ZONE=Europe/Moscow

4. Примените миграции:
   poetry run python manage.py migrate

5. Создайте суперпользователя:
   poetry run python manage.py createsuperuser

6. Запустите сервер разработки:
   poetry run python manage.py runserver

7. (Опционально) Запустите Celery worker и beat:

   В первом терминале:
   poetry run celery -A config worker -l info --pool=solo

   Во втором терминале:
   poetry run celery -A config beat -l info

### Запуск через скрипты (Windows)

Для запуска всех сервисов сразу выполните:
start_all_services.bat

## Документация API

После запуска сервера доступны следующие эндпоинты:

Основные эндпоинты:
- /admin/ — Админка Django
- /swagger/ — Документация API (Swagger UI)
- /redoc/ — Документация API (ReDoc)
- /api/auth/users/ — Регистрация пользователя (POST)
- /api/auth/jwt/create/ — Получение JWT токена (POST)
- /api/auth/jwt/refresh/ — Обновление токена (POST)
- /api/users/ — Управление профилем пользователя
- /api/habits/ — Управление привычками (создание, редактирование, удаление)
- /api/habits/public/ — Список публичных привычек (только чтение)
- /api/habits/pleasant/ — Список приятных привычек пользователя

Аутентификация:
Все эндпоинты защищены через JWT. Для доступа:
1. Зарегистрируйтесь: POST /api/auth/users/
2. Получите токен: POST /api/auth/jwt/create/
3. Добавляйте заголовок в запросы: Authorization: Bearer <ваш_токен>

Пример создания привычки с вознаграждением:
POST /api/habits/
Authorization: Bearer <токен>
{
  "place": "Дом",
  "time": "08:00",
  "action": "Пробежка",
  "duration": 120,
  "periodicity": 1,
  "reward": "Чашка кофе"
}

Пример создания приятной привычки:
POST /api/habits/
Authorization: Bearer <токен>
{
  "place": "Дом",
  "time": "08:30",
  "action": "Выпить чай",
  "is_pleasant": true,
  "duration": 60,
  "periodicity": 1
}

Пример привязки аккаунта к Telegram:
PATCH /api/users/<id>/
Authorization: Bearer <токен>
{
  "telegram_chat_id": 123456789
}

## Интеграция с Telegram

Настройка бота:
1. Создайте бота через @BotFather в Telegram
2. Добавьте токен в файл .env
3. Установите вебхук: GET /api/telegram/set-webhook/

Команды бота:
- /start — начать работу и получить свой ID чата
- /help — показать справку
- /habits — показать список ваших привычек
- /stats — показать статистику выполнения

## Celery задачи

Периодические задачи:
- Отправка напоминаний о привычках (каждые 15 минут + 07:00 ежедневно)
- Проверка неактивных привычек (09:00 ежедневно)
- Обновление дат следующих напоминаний (00:00 ежедневно)
